**Field groups (2026-11-27, all five sites).** Every collection's fields are grouped in the CMS editor, in this order: **SEO** first (what feeds the page title, meta description and share image; Name and Slug are Webflow's fixed fields above the groups and can't be grouped), then **Sort & filters** (what only orders or filters lists), then one group per page section, top to bottom as the page shows them. Each group's description says what its fields do. A field sits in one group only: one that is both SEO and on the page is in SEO.

| Collection | Groups, in order (fields in page order) |
| --- | --- |
| News Posts (editor-first, 2026-11-27) | Post type (External Article URL) · Sort & filters, all posts (Publish Date, Category) · Card, all posts (Cover Image, Source Name, Topics) · SEO, internal posts only (Excerpt) · Article page, internal posts only (Author, Read Time, Body) · Download card, internal posts only (Attachment Label, Attachment Size, Attachment) · Source card, internal posts only (Source URL). Help texts of internal-only fields start "Internal posts only – ignored for external links." The choice that decides which fields matter comes first, then what every card shows, then SEO and the article page for internal posts (outside articles have no page, so SEO no longer leads here) |
| Events | SEO (Summary, Image) · Sort & filters (Start, End) · Event head (Event Type, Tagline) · Detail bar (Location Note, Location) · Body · Perks · Callout · RSVP card (RSVP Provider, RSVP URL) |
| Documents | Sort & filters (Group, Show on Project Overview, Show on Community Impact, Order) · Doc accordion (Description, External URL, File) |
| FAQs | Sort & filters (Category, Show on Home, Order; on Chesapeake also Home Order, after Show on Home) · Accordion (Answer) |
| Testimonials | Sort & filters (Order) · Quote slider (Quote, Role, Photo) |
| Event Perks | Perk box (Value, Label) |
