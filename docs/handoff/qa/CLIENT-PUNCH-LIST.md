# Client punch list: all five campus sites

Merged 2026-11-26 from the launch QA reports in this folder (`justified.md`,
`muskie.md`, `lake-hawkeye.md`, `chesapeake.md`; `lake-mariner.md` is still
in progress, so its section lists the questions already known from the

answers them once. Everything here is waiting on TeraWulf; nothing is
waiting on Brand Vision.

   every campus, or send each campus's own people and footage? If you have
   the film's original export, please send it too: the copy we have is the
   old website's compressed version.

   - the small label above "How It Works" (it says "Lorem Ipsum");
   - the "Cooling Explained" video.
6. **Home FAQ order.** The designs open the home page FAQ with the water
   question. One order serves both the home page and the FAQ page. Which
   question should come first? (Justified, Muskie)
7. **Production domains and e-mail addresses.** Confirm each site's domain

   Our search-engine data already uses these domains.

   operators. Keep it, change it, or turn it off where there is no event?
9. **Photos.** Several pages reuse Lake Mariner photos, as the designs do.
   Do you have each campus's own photos for the heroes, the Project
   Highlights tabs, About TeraWulf, the event cards and the community
   cards?
10. **Sample events.** Each site has one "Sample Event" for review. We
    delete them before launch unless you want a real event in their place.
